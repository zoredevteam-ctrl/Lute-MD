## ⛓️ INSTALACIÓN

</div>

Sigue los pasos. No los cuestiones.

```bash
# Clona el repositorio
git clone https://github.com/tu-usuario/maki-md.git

# Entra en el directorio
cd maki-md

# Instala las dependencias
npm install

# Inicia el bot
npm start
```

Si algo falla, no es culpa mía. Revisa tus dependencias.

**Requisitos:**

| Componente | Versión mínima |
|---|---|
| Node.js | 18.x o superior |
| NPM | 9.x o superior |
| Conexión estable | Obligatoria |
